🚀 Installation de l'extension

Suivez ces 3 étapes simples pour capturer ChatGPT automatiquement

1 Téléchargez l'extension

Cliquez sur le bouton ci-dessous pour télécharger le fichier ZIP

2 Décompressez le fichier

Double-cliquez sur le fichier ZIP téléchargé pour le décompresser

3 Installez dans Chrome

  1. Ouvrez Chrome et allez à chrome://extensions/
  2. Activez "Mode développeur" en haut à droite
  3. Cliquez sur "Charger l'extension non empaquetée"
  4. Sélectionnez le dossier décompressé
✅ Extension installée ! Allez sur ChatGPT et cliquez sur l'icône de l'extension.
